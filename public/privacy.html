Privacy policy

Effective 27 November 2026

This policy covers Vergalin Backup, the family’s private backup tool, and this website, vergalin.com.

Who uses Vergalin Backup

Only one person uses Vergalin Backup: the family member who set it up. We do not offer it to anyone else.

What it reads and writes, and why

Vergalin Backup reads and writes files only in that person’s own Google Drive. It does so only to keep those files in sync with that person’s own computer.

Where the data goes

Nowhere else. The files move only between that Google Drive and that computer.

  • We run no server for the tool, and no copy is kept anywhere else.
  • We share no data with any third party.
  • We do not use the data for advertising, and we do not sell it.
  • We do not use the data to train artificial intelligence or machine learning models.

How the access is kept

The access token that Google issues stays on that computer, stored encrypted.

How to remove the access

The access can be removed at any time in the Google Account:

  1. Go to the Google Account’s linked apps page.
  2. Select Access to your Google Account, then select Vergalin Backup.
  3. Select Remove access, then Confirm.

Once the access is removed, Vergalin Backup can no longer reach the Google Drive.

Google’s Limited Use requirements

The use of information received from Google Workspace scopes will adhere to the Google User Data Policy, including the Limited Use requirements.

This website

vergalin.com sets no cookies, runs no scripts and does no tracking or analytics.

The site’s host processes each request, including the visitor’s IP address, only to deliver the page.

Contact

Write to the support email address shown on Vergalin Backup’s Google sign-in screen.
